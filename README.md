
# College Event Planning

## 1. Event Details
- Event Name: College Cultural Fest
- Venue: College Auditorium
- Date: To be announced
- Organized By: BBA Department

## 2. Event Objectives
- Encourage student participation.
- Develop leadership and teamwork.
- Improve communication skills.
- Provide a platform for student talents.

## 3. Activities
- Dance Competition
- Singing Competition
- Quiz Competition
- Paper Presentation
- Games and Cultural Events

- Event Coordinator: Overall planning
- Finance Team: Budget management
- Decoration Team: Venue decoration

- Technical Team: Sound and arrangements

## 6. Feedback
Feedback will be collected from participants after the event to improve future events.

## 7. Conclusion
This event planning project helps students develop teamwork, leadership and event management skills.
